# 牛马 AI（NewMax）配置教程

> 牛马 AI 最新名称为 NewMax。本文包含下载、登录、准备 Codesome API Key、选择分组、配置 V3 / 二合一的 Claude 和 Codex，以及连接测试。

## 1. 下载并安装 NewMax

打开 NewMax 官网下载页：

<https://newmax.cc/download>

根据你的系统下载安装包并完成安装。

![](<images/牛马 AI（NewMax）配置教程-image.png>)

## 2. 登录 NewMax

安装完成后打开 NewMax，点击登录按钮。

![](<images/牛马 AI（NewMax）配置教程-image-1.png>)

登录完成后，页面会显示授权成功。点击“打开 New Max”，返回 NewMax 软件界面。

![](<images/牛马 AI（NewMax）配置教程-image-2.png>)

## 3. 新建 API Key 并选择分组

在 NewMax 里添加模型前，先准备 Codesome API Key。V3 和二合一的 Key、分组和配置方式不同，不要混用。

### 3.1 V3 新建 API Key

1. 打开 `https://v3.codesome.cn/dashboard`。
2. 在左侧点击“API 密钥”。
3. 点击“创建密钥”。
4. 填写便于识别的名称，例如 `newmax-claude` 或 `newmax-codex`。
5. 选择与你购买的套餐和要使用的模型匹配的分组。
6. 创建后复制 `sk-...` API Key，并保存到安全位置。

不要把完整 API Key 发到公开群、截图或文档里。如果同时配置 Claude 和 Codex，建议分别创建对应分组的 API Key，避免混用。

### 3.2 二合一 API Key

1. 打开 `https://v5.codesome.cn`。
2. 使用二合一页面提供的 `cr-...` API Key。
3. 二合一不在 V3 后台选择或切换分组。

### 3.3 怎么选择分组

分组决定 API Key 使用哪一种模型、套餐和计费规则。可以按下面的规则选择：

| 你要配置的场景 | Key 和分组 |
|---|---|
| V3 Claude | 使用 `sk-...` Key，选择 `lite`、`pro` 或适合你的 Max 分组 |
| V3 Codex | 使用 `sk-...` Key，选择 `codex` 或对应的 Codex 月卡分组 |
| 月卡 | 选择与你购买套餐对应的月卡分组 |
| 按量 | 选择对应的按量分组 |
| 二合一 | 使用 `cr-...` Key，不需要选择 V3 分组 |

第三方客户端如果需要使用 Max，必须选择 `Max 2.2 可外接` 分组；其他 Max 分组只能在 Claude Code 中使用。

V3 查看或切换分组的入口是 `https://cc.codesome.ai/keys`。已经创建的 Key 可以在这里点击“编辑”，选择目标分组并保存。切换分组后，完全退出 NewMax 再重新打开并测试。

完整说明见[分组是什么、怎么选、怎么切换？](groups)。新建 API Key 的详细说明见[codesome｜使用问题速查](usage-faq)。

## 4. 在 NewMax 中添加自定义供应商

## 7. 测试连接并激活

填写完成后，点击“测试连接并激活”。

![](<images/牛马 AI（NewMax）配置教程-image-5.png>)

回到主界面，点击输入框右侧的模型选择按钮，选择刚才配置的 Codesome API 模型，然后发送一条消息测试。

![](<images/牛马 AI（NewMax）配置教程-image-8.png>)

能正常收到回复，就表示配置成功。

如果测试失败，先确认 V3 与二合一的 Key 没有混用，再检查 API Key 分组是否与 Claude / Codex 模型匹配。刚切换过分组时，请完全退出 NewMax，重新打开后再测试。
