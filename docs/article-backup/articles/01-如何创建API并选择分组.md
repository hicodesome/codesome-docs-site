# 如何创建 API 以及选择对应的分组

> 这篇只讲操作：怎么在后台创建一个 API Key，并在创建时选对你的分组。买什么产品、怎么兑换见文末「相关文档」；分组的概念、倍率和切换的详细说明见《分组是什么、怎么选、怎么切换？》。

## 一、先分清：兑换码 ≠ API Key

- **兑换码 / 卡密**：买完后拿到的凭证，用来在后台兑换或充值，**不能直接填进客户端**。
- **API Key**：兑换 / 充值之后，在后台「API 密钥」页面自己创建的一串密钥（V3 是 `sk-` 开头，二合一是 `cr-` 开头），这才是填进客户端的东西。

## 二、V3（月卡 / 按量）：创建 API Key

V3 的月卡、按量都在 `v3.codesome.cn`（`cc.codesome.ai` 是同一个后台）。

1. 打开 `https://v3.codesome.cn/dashboard`
2. 左侧点击「API 密钥」
3. 点击「创建密钥」
4. 填写名称，例如 `claude-code`、`codex` 或设备名
5. 选择分组（怎么选看第三节）
6. 创建后复制 `sk-` 开头的 API Key，保存到安全位置

创建完就可以去配置客户端了。

## 三、怎么选对应的分组

分组决定这个 Key 走哪条渠道、按什么倍率扣费。**分组是平台预设的，不能自己新建，只能在创建时选择、之后切换。**

| 你买的产品 | 该选的分组 | 说明 |
|---|---|---|
| 月卡 | 月卡分组（名称带 `month` 或额度金额，如 30 美金） | 月卡只能用月卡分组；切到按量分组会走按量余额 |
| 按量（Claude） | `lite` / `pro` / `Max` 系列 | 日常选 `lite` 或 `pro`；要满血性能选 `Max`（倍率更高） |
| 按量（GPT / Codex） | `codex` | 配 Codex / OpenCode 等客户端 |
| 二合一 | 不需要选分组 | `cr-` 卡密直接当 Key 用，在 `v5.codesome.cn` 使用 |

注意：

- **Max 分组**（`Max CC`、`Max 3.5`）只能 Claude Code 用；第三方客户端要用 Max，选「`Max 2.2 可外接`」。
- 选错分组的常见后果：月卡选了按量分组 → 扣按量余额；收到 403 → 先确认是不是分组没选对。
- 分组倍率和可用性是动态的，以当天后台显示为准。

## 四、V5（二合一）：不用创建，直接用 cr- Key

二合一没有分组选择：

1. 打开 `https://v5.codesome.cn`（`aio.codesome.ai`）
2. 订单里的 `cr-` 卡密就是 API Key，不需要兑换、不需要创建
3. Claude Code 使用 `https://v5.codesome.cn/api`；Codex / OpenAI 格式客户端使用 `https://v5.codesome.cn/openai`

## 五、创建后怎么确认

1. 回后台「API 密钥」列表，确认这个 Key 挂着的分组是你想用的。
2. 客户端里填好 Key 和请求地址，完全退出后重新打开，发一句"请回复 OK"。
3. 能正常回复就说明可用；想更严格，可在后台「调用记录」核对 Provider、分组、模型是否一致。

## 六、常见问题

| 问题 | 答案 |
|---|---|
| 兑换码能直接当 API Key 用吗？ | 不能。兑换码用于兑换 / 充值；API Key 要在后台自己创建 |
| 创建时忘了选分组怎么办？ | 在「API 密钥」列表编辑该 Key 改分组，改完重启客户端 |
| 分组能自己新建吗？ | 不能。分组是平台预设的，只能选择或切换 |
| 月卡能选 Max 分组吗？ | 不能。月卡只能用月卡分组，Max 走按量额度 |
| 二合一要不要创建 Key？ | 不用。`cr-` 卡密直接当 Key 用，不去 V3 兑换 |
| 多个 Key 怎么来回切换？ | 用 CC Switch 之类的工具一键切换不同分组的 Key |
