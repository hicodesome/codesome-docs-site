# 如何查询我的余额和用量（网页与 API）

> 想确认 API Key 是否有效、还剩多少余额或额度、最近用了多少 Token，先确认自己使用的是 V3 还是 V5。两套产品的 Key、后台和查询入口不同，不能混用。

## 30 秒结论

| 你的产品或方式 | 查询内容与入口 |
|---|---|
| V3（Claude 月卡、GPT 月卡、按量） | 余额、API Key、用量记录：[V3 后台](https://v3.codesome.cn/dashboard) |
| V3 月卡 | 月卡额度和到期时间：[订阅页](https://v3.codesome.cn/subscriptions) |
| V3 API Key 查询 | 余额、额度和用量：`GET /v1/usage` |
| V5（二合一） | 用量和到期时间：[V5 统计查询页](https://v5.codesome.cn/admin-next/api-stats) |

一句话判断：Claude 月卡、GPT 月卡和按量都属于 V3；只有二合一使用 V5。

## 1. 先确认自己是 V3 还是 V5

### V3

- 产品：Claude 月卡、GPT 月卡和按量。
- Key：先在 V3 兑换，再到后台创建 `sk-...` API Key。
- 管理入口：`https://v3.codesome.cn/dashboard`。

### V5（二合一）

- 产品：二合一。
- Key：订单中的 `cr` 开头卡密直接作为 API Key，不到 V3 兑换。
- 查询入口：`https://v5.codesome.cn/admin-next/api-stats`。

如果不确定，先看订单中的产品名称。不要把 V5 二合一 Key 粘贴到 V3，也不要用 V3 Key 查询 V5。

## 2. V3：在网页查看余额、额度和用量

最简单的方法是打开 V3 后台：

`https://v3.codesome.cn/dashboard`

登录后可以查看账户余额、API Key 和用量记录。需要查看月卡额度或到期时间时，打开：

`https://v3.codesome.cn/subscriptions`

如果网页显示的账户余额与某个 Key 的可用额度不同，还要检查这个 Key 是否设置了累计额度上限。单个 Key 的累计上限不会因为账户仍有余额就自动解除。

## 3. V3：直接用 API Key 查询

V3 支持通过下面的接口查询：

```text
GET https://cc.codesome.ai/v1/usage
Authorization: Bearer <你的 V3 API Key>
```

在自己的终端执行：

```bash
curl -sS \
  -H "Authorization: Bearer sk-请替换为你的V3-API-Key" \
  https://cc.codesome.ai/v1/usage
```

不需要请求体，也不需要账号密码。请只在自己的可信设备上执行，不要把带有真实 Key 的完整命令发到群聊、工单、截图或在线命令工具中。

### 常见返回字段

| 字段 | 含义 |
|---|---|
| `isValid` | API Key 当前是否有效 |
| `mode` | `quota_limited` 表示按 Key 限额/订阅额度返回；`unrestricted` 表示按账户订阅或钱包余额返回 |
| `planName` | 当前套餐或余额类型名称 |
| `remaining` | 当前可用余额或额度 |
| `balance` | 钱包余额模式下的余额；其他模式不一定返回 |
| `unit` | 金额或额度单位 |
| `usage` | 累计请求数、Token 和费用统计 |
| `daily_usage` | 按日用量 |
| `model_stats` | 各模型的请求数、Token 和费用统计 |

不同套餐返回的字段可能不同。判断“还能不能用”时，先看 `isValid`、`mode` 和 `remaining`；账户最终余额与订阅状态仍以 V3 后台为准。

### 查询最近 7 天

```bash
curl -sS \
  -H "Authorization: Bearer sk-请替换为你的V3-API-Key" \
  "https://cc.codesome.ai/v1/usage?days=7"
```

### 查询指定日期范围的模型用量

```bash
curl -sS \
  -H "Authorization: Bearer sk-请替换为你的V3-API-Key" \
  "https://cc.codesome.ai/v1/usage?start_date=2026-07-01&end_date=2026-07-29"
```

`days` 支持 1 至 90；日期使用 `YYYY-MM-DD` 格式，请按需要替换示例日期。

## 4. V5（二合一）：在专用页面查询

V5 二合一不使用 V3 的 `/v1/usage`。请按下面操作：

1. 打开 `https://v5.codesome.cn/admin-next/api-stats`。
2. 输入订单中 `cr` 开头的二合一 API Key。
3. 点击“查询统计”。
4. 查看今日、月度和累计请求数、Token、费用、限制及额度窗口信息。

有多个 V5 Key 时，页面也支持切换到多 Key 查询；只查一个 Key 时保持默认的单一模式即可。

请在自己的可信设备上使用查询页。不要把完整 Key 发给他人，也不要在带 Key 的页面截图后直接公开。

## 5. 常见问题

### 返回 `API_KEY_REQUIRED`

请求没有带 `Authorization` 头，或 Bearer 后面没有实际 Key。检查命令是否完整，并确认 Key 前后没有多余空格。

### Key 明明存在，却提示无效或查询失败

先确认产品线是否混用：V3 常见是 `sk-...` Key，V5 二合一是 `cr` 开头 Key。然后检查 Key 是否已被禁用、删除、重置或过期。

### 账户还有余额，客户端却提示额度不足

V3 用户进入后台的“API 密钥”页面，检查当前 Key 是否设置了累计额度限制，以及 Key 分组是否与已购产品匹配。账户余额和单个 Key 的上限是两回事。

### 查询结果为什么没有 `balance`

`balance` 主要用于钱包余额模式。月卡、订阅或设置了 Key 限额时，重点看 `mode`、`remaining` 和套餐信息；最终状态以对应后台页面为准。

### API Key 泄露了怎么办

V3 Key 泄露后，立即进入 V3 后台禁用或删除旧 Key，再创建新 Key，并替换所有客户端中的旧值。V5 二合一 Key 泄露时，请私聊客服处理，不要在群里再次发送完整 Key。
