# 分组是什么、怎么选、怎么切换？

分组是 Codesome 里很常见、也很容易搞混的一个概念。这篇文章从"分组是什么"讲起，告诉你分组的入口在哪、有哪些分组、倍率怎么算，以及如何切换分组。

---

## 一、分组是什么

分组决定你的 API Key 走哪一种渠道 / 套餐 / 模型 / 计费规则。

- 你买的月卡、按量、二合一，最后都体现在你创建的 API Key 上挂着的那个分组。
- 每个 API Key 创建时都要选一个分组。
- 选分组主要看你想用哪种模型：

| 你想用 | 选什么分组 |
|---|---|
| Claude 模型 | Lite / Pro / Max |
| GPT 模型 | Codex |
| 月卡 | 月卡分组 |
| 按量 | 按量分组 |

一句话：分组就是你 API Key 的"通道"，决定了这个 Key 用什么资源、按什么倍率扣费。

---

## 二、分组的入口在哪

V3 的分组入口在这里：

https://cc.codesome.ai/keys

打开后直接看你的 API 当前选的是哪个分组；要切换分组也在这里操作。

几个相关入口：

| 用途 | 地址 |
|---|---|
| V3 查看 / 切换分组 | https://cc.codesome.ai/keys |
| 二合一（V5，`cr-` Key，无分组选择） | https://v5.codesome.cn |
| 配置客户端时的请求地址 | https://cc.codesome.ai |

注意：`cc.codesome.ai/keys` 是管理分组用的后台页面；`cc.codesome.ai` 是配置客户端时填的请求地址。两者是同一个域名下的不同用途，别混。

---

## 三、有哪些分组、倍率怎么算

扣费公式：实际扣费 = 官方单价 × token 数量 × 分组倍率。

### Claude 侧分组（V3）

| 分组 | 来源 | 适合 | 倍率 |
|---|---|---|---|
| `lite` | 反代 | 日常、成本敏感 | 1.5 |
| `pro` | 反代 | 日常 | 1.5 |
| `Max CC`（= `Max 2.2`） | 官方 Max 200x 订阅 | Claude Code 满血 | 2.2 |
| `Max 3.5` | 官方 Max 200x 订阅 | Claude Code 满血 | 3.5 |
| `Max 2.2 可外接` | 官方 Max 200x 订阅 | 第三方客户端 | 2.2 |
| 月卡分组 | 月卡订阅 | 对应月卡额度 | 1.5 |

> `fable` 模型目前只有 `Max CC`（Max 2.2）和 `Max 3.5` 能调用。

### GPT / Codex 侧

| 分组 | 来源 | 说明 | 倍率 |
|---|---|---|---|
| `codex` / `codex1.0` | ChatGPT Pro 订阅 | 配 Codex / OpenCode 等客户端 | 按量 1.0；月卡 1.5 |

### 其他

- **二合一**：没有分组选择，Claude 和 GPT 两类模型都按 1.5 倍。
- **生图**：OpenAI Image 2 生图按量分组，需单独联系开通，仅支持按量。

### 倍率小结

| 场景 | 倍率 |
|---|---|
| Codex 按量 | 1.0（最划算） |
| Codex 月卡 / 标准分组 / 二合一 | 1.5 |
| `Max CC`、`Max 2.2 可外接` | 2.2 |
| `Max 3.5` | 3.5 |

几个要点：
- **Codex 按量最划算**：1.0 倍，是唯一按原始单价计费的；Codex 走月卡则上浮到 1.5 倍。
- **二合一没有分组可切**，所以是"一张卡统一 1.5"，不存在"切分组改倍率"。
- **标准分组统一 1.5 倍**，不区分月卡还是按量。
- **Max 系列三个分组**：`Max CC`（= Max 2.2，2.2 倍）、`Max 3.5`（3.5 倍）、`Max 2.2 可外接`（2.2 倍）。前两个只能 Claude Code 用；`Max 2.2 可外接` 是唯一能接第三方客户端的 Max 分组。
- 倍率和分组可用性是动态运营值，文中数字以当天后台为准。

## 四、怎么切换分组

### 方式一：同一个 Key 在后台直接改分组（最常用，不用新建）

1. 打开 https://cc.codesome.ai/keys
2. 找到已经配置进你客户端的那个 Key
3. 点"编辑"
4. 选目标分组：
   - 月卡分组：名称带 `month` 或额度金额（如 30 美金）字样；
   - 按量：选 `lite` / `pro` / `max` 系列；
   - GPT：选 `codex`。
5. 保存
6. 完全退出客户端，重新打开，发一句"请回复 OK"验证

### 方式二：建多个不同分组的 Key，在客户端里一键切换

如果你经常在月卡和按量之间切换，可以建几个不同分组的 Key，用 CC Switch 之类的工具一键切换，这样最不容易把自己切乱。

**注意**：
- 切换分组后生效可能有一点延迟。
- 切换到 Max 分组后，一定要新开窗口再测试。

---

## 五、切换后怎么验证

1. **新开一个窗口 / 新会话**再测试（尤其切到 Max 后）。
2. 发一句简单消息，能正常回复就算成功。
3. 想更严格确认，回后台调用记录看 Provider、分组、模型是否一致。

**常见坑**：后台已经切到 Max，但还在旧窗口里问，会表现为"像没切成功"。这不是没切上，是旧窗口沿用了旧会话状态，新开窗口即可。

---

## 六、几个重要的规则

1. **月卡只能用月卡分组**。切到按量分组会走按量余额，月卡额度带不过去。
2. **Max 分组只能用在 Claude Code**。第三方客户端要用 Max，必须选 `Max 2.2 可外接` 分组。
3. **切到 Max 后必须新开窗口**，旧窗口沿用旧状态会误判。
4. **分组可用性会变动**（波动、下架、封号等），遇到波动可暂时切换到其他可用分组。
5. 收到 403 之类报错时，先确认是不是月卡没切到月卡分组。
6. **二合一（`cr-` Key）不用、也不能在 V3 后台切分组**。

## 七、常见问题速查

| 问题 | 答案 |
|---|---|
| 分组是什么？ | 分组＝你的 API Key 走哪条渠道/套餐/模型/计费；月卡选月卡分组、按量选按量分组、GPT 选 codex |
| 分组在哪看？ | https://cc.codesome.ai/keys，每个 Key 上显示的分组就是 |
| 怎么切换分组？ | 后台找到 Key → 编辑 → 选目标分组 → 保存 → 重开客户端发"请回复 OK" |
| 月卡能切 Max 吗？ | 不能。月卡只能用月卡分组，Max 走按量额度 |
| 第三方客户端用 Max 报错？ | Max 只能 Claude Code 用；第三方用 `Max 2.2 可外接`，或切 `lite` / `pro` |
| fable 怎么用？ | 目前 `Max CC`（Max 2.2）和 `Max 3.5` 可调用 |
| Codex 倍率？ | 按量 1.0 倍（最划算），月卡 1.5 倍 |
| 二合一倍率？ | 无分组选择，两类模型统一 1.5 倍 |
| V3 倍率？ | 标准分组统一 1.5 倍 |
| Max 有几个？ | 三个：`Max CC`（2.2）、`Max 3.5`（3.5）、`Max 2.2 可外接`（2.2） |
| Max 怎么接第三方客户端？ | 用 `Max 2.2 可外接` 分组 |
| 切换后还报错？ | 先新开窗口再测；再看分组是否波动，可暂时换个分组试试 |
| 一个 Key 能来回切吗？ | 能，后台直接改该 Key 的分组即可 |
| 二合一要切分组吗？ | 不用，`cr-` Key 直接配 V5，不在 V3 操作 |

---

最后提醒：分组倍率和可用性是动态的，文中数字以当天后台为准。
